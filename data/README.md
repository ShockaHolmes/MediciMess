# Data Directory

This folder stores generated transaction datasets used by the MediciMess project.

## Contents

- `medici_transactions.csv` - generated historical transaction dataset
- `medici_transactions.json` - generated historical transaction dataset in JSON format
- `exported_transactions.csv` - sample export created by the import/export demo
- `exported_transactions.json` - sample export created by the import/export demo

## Notes

These files are generated by the project scripts and can be recreated at any time.
